================================================================================
                    CLI Utils - Required Programs Reference
================================================================================
This document lists all programs that should exist on your system for CLI Utils
to function properly. Programs are categorized by their purpose.

================================================================================
                    🔴 REQUIRED BY PYTHON SCRIPTS (Must Install)
================================================================================
These programs are actually called by the Python scripts and will fail without them.

1. ffmpeg.exe - Video encoding/decoding/transcoding
   - Version: Latest (use winget for auto-update)
   - Install: winget install ffmpeg
   - Used by: ffcomp.py, ffcompare.py, ffcover.py, mkpdf.py, fffunctions.py
   - Required for: Video compression, cover art embedding, format conversion

2. 7-Zip (7z.exe) - Archive extraction/compression
   - Version: Latest (use winget for auto-update)
   - Install: winget install 7zip
   - Used by: archive-extractor.py
   - Required for: Archive file extraction

3. EXIFTool - Metadata extraction/embedding
   - Version: Latest (use winget for auto-update)
   - Install: winget install exiftool
   - Used by: imgconv.py, mkpdf.py, ffcover.py, MetaDupe.py
   - Required for: Metadata operations on images and videos

OTHER TOOLS

================================================================================
                    🟢 OPTIONAL/EXTERNAL PROGRAMS (NOT Python packages)
================================================================================
These are compiled programs that are executed as subprocesses.
They are NOT Python dependencies but must be installed separately.

Image Optimizers (External executables)
 - oxipng.exe   - PNG optimization
 - ect.exe      - EXIF extraction (likely external tool)
 - jpegoptim.exe - JPEG optimization
 - cwebp.exe    - WEBP compression (libwebp)
 - cjxl.exe     - JPEG-XL conversion

================================================================================
                    📋 QUICK INSTALL COMMANDS (Windows)
================================================================================

# Install all required programs
winget install ffmpeg
winget install 7zip
winget install exiftool

# Optional: Install image optimizers
winget install oxipng
winget install zopfli

# Verify installations
ffmpeg -version
7z -v
exiftool --version
